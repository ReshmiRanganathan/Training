Exercise 1 – Remove Duplicates from a List

You are given a list of customer IDs.

2. Print unique customers

Exercise 2 – Frequency Counter

Given a list of numbers:

numbers = [10,20,10,30,20,10,40]

Tasks
1. Count how many times each number appears
2. Store the result in a dictionary
Expected structure

{10:3, 20:2, 30:1, 40:1}

CODE:
numbers = [10,20,10,30,20,10,40]
freq = {}
for num in numbers:
    freq[num] = freq.get(num, 0) + 1
print(freq)





Exercise 3 – Student Marks Analyzer

students = {
"Rahul":85,
"Sneha":92,
"Arjun":78,
"Priya":88
}

Tasks
1. Print the topper
2. Print average marks
3. Print students scoring above 85

CODE:
students = {"Rahul":85,"Sneha":92,"Arjun":78,"Priya":88}
topper = max(students, key=students.get)
average = sum(students.values()) / len(students)
print("Topper:", topper)
print("Average Marks:", average)
print("Students scoring above 85:")
for name, mark in students.items():
    if mark > 85:
        print(name)

Exercise 5 – Email Domain Extractor

emails = [
"user1@gmail.com",
"user2@yahoo.com",
"user3@gmail.com",
"user4@outlook.com"
]

Tasks
1. Extract domains
2. Count how many users per domain
Expected output

{
"gmail.com":2,
"yahoo.com":1,
"outlook.com":1
}

CODE:
emails = ["user1@gmail.com","user2@yahoo.com","user3@gmail.com","user4@outlook.com"]
domains = {}
for email in emails:
    domain = email.split("@")[1]
    domains[domain] = domains.get(domain, 0) + 1
print(domains)

Exercise 8 – Word Counter

Given a sentence

sentence = "python is easy and python is powerful"

1. Count frequency of each word
2. Store results in dictionary
Expected output

{
"python":2,
"is":2,
"easy":1,

Exercise 9 – Highest Selling Product

sales = [
{"product":"Laptop","qty":5},
{"product":"Mouse","qty":20},
{"product":"Laptop","qty":3},
{"product":"Keyboard","qty":10}
]

Tasks
1. Calculate total sales per product
2. Find highest selling product

CODE:
sales = [{"product":"Laptop","qty":5},{"product":"Mouse","qty":20},{"product":"Laptop","qty":3},{"product":"Keyboard","qty":10}]
total = {}
for item in sales:
    product = item["product"]
    qty = item["qty"]
    total[product] = total.get(product, 0) + qty
highest = max(total, key=total.get)
print("Total Sales:", total)
print("Highest Selling Product:", highest)

Exercise 11 – E-commerce Order Analysis

orders = [
{"order_id":1,"customer":"Rahul","amount":2500},
{"order_id":2,"customer":"Sneha","amount":1800},
{"order_id":3,"customer":"Rahul","amount":3200},
{"order_id":4,"customer":"Amit","amount":1500}
]

Tasks
1. Calculate total spending per customer

2. Find highest spending customer
3. Count total orders per customer

CODE:
orders = [{"order_id":1,"customer":"Rahul","amount":2500},{"order_id":2,"customer":"Sneha","amount":1800},{"order_id":3,"customer":"Rahul","amount":3200},{"order_id":4,"customer":"Amit","amount":1500}]
spending = {}
count = {}
for order in orders:
    customer = order["customer"]
    amount = order["amount"]
    spending[customer] = spending.get(customer, 0) + amount
    count[customer] = count.get(customer, 0) + 1
highest = max(spending, key=spending.get)
print("Total Spending:", spending)
print("Highest Spending Customer:", highest)
print("Total Orders:", count)
